# Publish this as your GitHub profile

GitHub renders a profile README only from a public repository whose name exactly matches the account username: `Ashotsim05`.

1. Create `Ashotsim05/Ashotsim05` on GitHub (empty, public repository).
2. Copy the contents of this folder into that repository root:
   - `README.md`
   - `assets/ashot-mark.svg`
3. Commit and push to `main`.

The profile intentionally publishes your professional email, LinkedIn, GitHub handle, and city because they are present in the CV and useful for hiring. It deliberately omits the CV phone number and exact street address.
